# HMS-Hospital-Management-System

HMS is a Hospital Management System website.In this mainly 5 modules

1. Patient-patient register,login,doctor appointment,payment,token email as acknowledge.
2. Doctor-Doctor register,login,Appointments view,approve,update,cancel,apply for leave.
3. Nurse-Nurse register,login,apply for leave,their shift and duty of department.
4. Receptionst-Receptionist register,login,view bookings,provide token to patient.
5. Hr-Hr register,login,apply leave check leaves of doctor,Nurse,etc,calculate payments
